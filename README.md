# Projects_made_by_atul
MATLAB project that calculates frictional pressure drop in a circular pipe using the Darcy-Weisbach equation, ΔP = f(L/D)(ρv²/2). It computes velocity, Reynolds number and friction factor (laminar or Swamee-Jain turbulent) for 100 flow rates, then plots pressure drop vs flow rate.
